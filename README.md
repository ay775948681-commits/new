# 待办清单（简易 Todo Web 应用）

一个使用**原生 HTML / CSS / JavaScript**实现的待办事项应用，无任何框架和构建依赖。
支持添加、勾选完成、删除、行内编辑、筛选，数据通过浏览器 `localStorage` 持久化，刷新页面不丢失。

## 功能

- ✅ **添加待办**：输入内容后按 `Enter` 或点击「添加」按钮；空白内容会被拦截并提示
- ✅ **勾选完成**：点击复选框切换完成状态，文字加删除线，底部统计同步更新
- ✅ **删除待办**：点击每行右侧的 `×` 删除
- ✅ **双击编辑**：双击待办文字进入行内编辑，`Enter` 保存、`Esc` 取消
- ✅ **筛选视图**：全部 / 未完成 / 已完成
- ✅ **清除已完成**：一键移除所有已完成项
- ✅ **数据持久化**：所有变更实时写入 `localStorage`（键名 `todo-app.items.v1`），刷新后自动恢复

## 本地启动

不需要安装任何依赖，任选一种方式：

### 方式一：Python 内置服务器

```bash
cd 本仓库根目录
python -m http.server 8080
```

然后浏览器访问 <http://localhost:8080>

### 方式二：Node.js

```bash
npx serve .        # 或 npx http-server -p 8080
```

### 方式三：直接打开

双击 `index.html` 用浏览器打开即可（`localStorage` 在 `file://` 协议下同样可用）。

> 要求：任意现代浏览器（Chrome / Edge / Firefox / Safari 均可）。

## 自动化验证

仓库内置基于**真实无头浏览器（Edge/Chrome）+ CDP 协议**的端到端验证脚本，
不依赖任何 npm 包（使用 Node.js 22+ 内置的 `fetch` 与 `WebSocket`）。

```bash
# 需要本机装有 Edge 或 Chrome；Node.js >= 22
node tests/verify.mjs

# 浏览器不在默认位置时，可显式指定
EDGE_PATH="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" node tests/verify.mjs
```

脚本会启动本地静态服务器与无头浏览器，依次验证 12 个场景：

| 编号 | 场景 | 验证内容 |
| ---- | ---- | -------- |
| T1 | 初始状态 | 空列表、空态文案、统计、按钮禁用态 |
| T2 | 点击添加 | 添加 3 条待办并按序显示 |
| T3 | 空白拦截 | 空白输入不产生新条目，出现错误提示 |
| T4 | 键盘添加 | `Enter` 提交并清空输入框 |
| T5 | 勾选完成 | `data-done`、删除线样式、统计文案同步 |
| T6 | 删除 | 指定条目被移除 |
| T7 | 存储一致 | `localStorage` 内容与界面一致 |
| T8 | 刷新持久化 | 刷新后条目、完成状态、顺序均恢复 |
| T9 | 筛选 | 未完成 / 已完成 / 全部 三个视图正确 |
| T10 | 行内编辑 | 双击编辑并保存，存储同步 |
| T11 | 清除已完成 | 只移除已完成项 |
| T12 | 清空 | 全部删除后回到空状态，存储为 `[]` |

全部通过时输出 `结果：12/12 项通过` 并以退出码 `0` 结束。

### 手动验证清单

1. 打开页面 → 应看到空状态提示「还没有待办」
2. 输入「写周报」→ 按 `Enter` → 列表出现该条目
3. 直接点击「添加」→ 出现「请输入待办内容。」提示，列表不变
4. 勾选「写周报」→ 文字加删除线，底部统计变为「共 1 项 · 已完成 1 项」
5. 点击 `×` 删除该条 → 列表回到空状态
6. 添加几条并勾选部分完成后**刷新页面（F5）**→ 条目与完成状态完整保留
7. 打开 DevTools → Application → Local Storage → 可见键 `todo-app.items.v1`

## 技术说明

- **零依赖**：无框架、无构建步骤、无第三方库
- **安全渲染**：用户输入通过 `textContent` 写入 DOM，避免 XSS
- **容错**：`localStorage` 读写均做了异常捕获（隐私模式 / 存储被禁用时有提示），损坏的历史数据会被安全忽略
- **存储格式**：`[{ id, text, done, createdAt }]`，文本上限 120 字符
